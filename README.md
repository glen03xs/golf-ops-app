# Golf Course Operations App (`golf-ops-app`)

Monorepo containing the modern operations engine for golf course management, facility booking, and SOP knowledge retrieval.

## Repository Structure
- `/backend`: Django 5.x, Django Ninja API, Python 3.14, PostgreSQL + `pgvector`.
- `/frontend`: Next.js App Router, React, Tailwind CSS (Coming Week 2).
- `docker-compose.yml`: Local infrastructure orchestrator.
